## 12.1 呼び名の変更（表示だけ）

| 変更前 | 変更後 | 表示例 |
|---|---|---|
| 🐷 ためメシ | 🐷 メシため | ボタン「🐷 メシため +150pt」 |
| 運動 | 🏃 うごため | ボタン「＋うごため」、内訳「🏃 うごため +◯pt」 |

- 画面に出る文言はすべて置き換える（ボタン、内訳、振り返り、トースト、設定画面、メニュー例のシートなど）。「ためメシ」「運動」で grep して漏れがないようにする
- DBに保存している値、型、変数名などの内部キーは変えない。表示ラベルだけを変える
- pt の計算（メシため +150pt、うごためのpt表）は変更しない

## 12.2 食べものの辞書と、目安の例の内訳

### 単品の辞書
- 「おにぎり（鮭）1個 ≒ 180kcal」のような単品の辞書を用意し、チートのアイテム表（lib/cheatItems.ts）と同じ辞書を共有する
- 既存の lib/cheatItems.ts の構造を確認したうえで、「cheatItems.ts を拡張する」か「lib/foodItems.ts を新設して cheatItems から参照する」かを提案してから進める
- 各項目：id、名前、単位（個・杯・皿など）、kcal。kcal は一般的なざっくりの値でよい

### 目安の例（lib/mealExamples.ts）
- 各例は「辞書の id × 数量」の組み合わせで定義する。合計 kcal は手で書かず、lib/calories.ts の純粋関数で辞書から計算する
- 例の数を増やす：朝・昼・夜それぞれ「目安くらい」「がっつり」を各8〜10個程度。和・洋・中・コンビニ・外食などジャンルを散らす
- 例の行をタップすると内訳を展開する（例：おにぎり（鮭）1個 180kcal／カップ麺1個 350kcal …）。同時に開くのは1つだけ。最初は閉じた状態
- がっつりのしきい値表示は50kcal単位で切り上げる（1049kcal〜 → 1050kcal〜）。丸めは lib/calories.ts の関数で行う

## 12.3 メシポゲージと振り返りを1枚のカードに統合

今日画面の「メシポゲージ」と「今週の振り返り」カードを、1枚の「◯月のメシため」カードにまとめる。別の振り返りカードは削除する。

### カードの構成（上から）
1. ヘッダー：「◯月のメシため」、右に「＋うごため」「＋チート」ボタン
2. 見出し（下記「見出しの文言」）
3. ゲージ（チートのアイコンが乗る。下記「ゲージ」）
4. サブ行：「ゼロカロ化 ◯ / ◯kcal」＋次のチートまでの案内
5. 体重の一言（12.4）
6. カードの下に「今週 +◯pt」の1行（12.5）

カード本体をタップすると、これまでの内訳（メシため◯回・うごため◯pt・チート一覧と各コスト）を展開する。

### ゼロカロ化の考え方
- pt ≒ kcal なので、「貯まったpt」＝「実質0kcalにできたkcal」として表示する
- 今月のチート（事前登録・途中追加・がっつり）を並び順に累計し、累計コストが貯まったpt以下のチートを「0kcal化済み」とする
- 並び順：日付のあるものは日付の早い順、日付のないもの（頻度ベースなど）はその後ろに登録順。既存のデータ構造でこの並びが作りにくい場合は、代案を出して確認を取る
- がっつりは「🔥がっつり（11/5 夜）」のような1件のチートとして並べる

### 見出しの文言
- 0kcal化済みが1件以上：「{チート名を「・」でつなぐ（最大3件、それ以上は「ほか◯件」）}、実質0kcalで ごちそうさまでした」
  - 例：「ワイン1本・ハイボール1杯、実質0kcalで ごちそうさまでした」
- チートはあるが0kcal化済みが0件：「最初のチートまで、あとメシため◯回」
- チートが未登録：「食べたいものを先に決めよう」（＋チートへ誘導）
- 見出しには0kcal化済みのものだけを入れる（まだのものは入れない）

### ゲージ
- 横棒の上に、各チートの絵文字（アイテム表のジャンルの絵文字。がっつりは🔥）を累計コストの位置に置く
- 0kcal化済みはアクセント色（amber-400）、まだのものはグレー
- アイコンが近すぎて重なる場合は1つにまとめて「×2」のように表示
- これまでのペースの目印（縦線）と「ペースどおり」の文字は表示しない（シンプルにするため）

### サブ行
- 「ゼロカロ化 600 / 630kcal」
- まだのチートがある場合：「・あとメシため◯回で{次のチート名}も0kcal」（◯ = 残りkcal ÷ 150 を切り上げ）
- 全部0kcal化済みの場合：これまでどおり「あと◯kcal分、チートを追加できます」（翌月に持ち越さない）
- マイナスの数字は出さない

### 0kcalになった瞬間
- メシため・うごためを記録した結果、新たにチートが0kcal化済みになったら、トーストで「{チート名}、なかったことに。」を2〜3秒表示する
- 一度に複数なった場合は最後の1件だけでよい

## 12.4 体重の見せ方（「7日平均」という言葉を出さない）

### カードの一言
- 「これだけ食べて、月初めから0.4kg減」／「変わらず」／「0.2kg増」
- 計算（lib/calories.ts の純粋関数）：
  - 基準 = その月で最初に体重を記録した日から7日間の記録の平均（3件以上あるとき）
  - いま = 今日までの直近7日間の記録の平均（3件以上あるとき）。基準の期間と重ならないこと
  - 差が0.1kg未満なら「変わらず」。表示は小数1桁
  - 条件が揃わないとき（月の初めなど）は、この一言を表示しない

### 体重タブ
- 「7日平均 102.4kg（参考値）」→「このところ 102.4kg前後」に変える（計算は今の7日平均のまま）

## 12.5 今週の行（振り返り）

- カードの下に「今週 +◯pt」の1行だけを表示（週は月〜日、日本時間）
- タップで内訳を展開：🐷メシため◯回 +◯pt ・ 🏃うごため +◯pt ・ 今週食べたチート。最初は閉じた状態
- 日曜は今週、月曜は先週の分について、この1行を既存の振り返り文（「今週は+300pt！ケーキ1個ぶん貯まりました🍰」相当）に置き換える

## 12.6 変えないもの

- pt の値、目標の計算、毎日の目安の計算
- DBの列名・保存値（マイグレーションは不要の想定。必要になった場合は理由を添えて確認を取る）
