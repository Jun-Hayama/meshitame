## 2. 「◯月のチート」カードを短くする
### 形（まだの分があるとき）
```
11月のチート                              ›
レモンサワー約32缶ぶん飲んで、体重はそのまま

チート                           5,670kcal
[■■■■■■■■■■■■■■■■■■■■■■■■■■▨▨▨]
貯めた  🐷22回 🏃9回    5,535kcal  あと135kcal

🚶 30分歩けば、なかったことに  ［記録する］ ヒント ›
```
- 大きな文字の「あと◯kcalで、なかったことにできます」の行はなくします（棒の下の「あと◯kcal」と重なるため）。
- 「いちばん手軽に届く方法」と「ヒント ›」を1行にまとめます。
  - 300kcal以下：「🚶 30分歩けば、なかったことに」＋［記録する］＋「ヒント ›」
  - 300kcalより多い：「どうやって届く？」＋「ヒント ›」（amber で目立たせる）
- 余りがあるとき（「チートにあと◯kcal使えます」＋2つのボタン）、チートも貯めた分も0のとき（コンセプトの一文）は今のまま。
- 予定の行は今のまま、一番下に出します。

## 3. 今日の画面
- 今朝の体重の下の「このところ ◯kg前後」は、今日の画面からなくします（体重タブで見られるので）。
- 並びは今のまま：今朝の体重 → ◯月のチート → 今日の記録。
- **今日の記録の中を2つに分けます。**
```
今日の記録                              ［目安］

ごはん
朝   🐷メシため  🍚いつもの  🔥チート
昼   🐷メシため  🍚いつもの  🔥チート
夜   🐷メシため  🍚いつもの  🔥チート
追加チート  おやつ・お酒・2軒目など        ＋

うごき
今日は 🚶30分・👣8,000歩
［🚶 30分 150kcal］［🏃 20分 200kcal］［＋うごため］
```
- 「ごはん」「うごき」は、今日の記録の中の小見出し（今日の記録より小さい文字）にします。
- 「今日うごく？」の見出しと、［👣歩数］［…］のボタンはなくします。歩数や、ほかの種類・時間は［＋うごため］（今のうごための画面）から入れます。
- 「今日は 🚶30分・👣8,000歩」の行は、その日にうごためがあるときだけ出します（今のまま）。

## 4. いつものうごため（lib/calories.ts の純粋関数＋テスト）
- うごきのワンボタンは2つ。設定画面は作らず、**よく記録するものを自動で並べます。**
  - 直近30日のうごための記録（歩数の記録は除く）を「種類×時間（分）」でまとめ、回数の多い順に上位2つ。回数が同じなら、最後に記録した日が新しいほうを先にします。
  - 2つに足りないときは、ウォーキング30分、ランニング30分の順で埋めます（同じものは重ねない）。
- ボタンの表示：「🚶 30分 150kcal」（種類の絵文字・分・kcal）。kcal は既存のkcal/分から計算します。
- 押すとその場で保存し、トーストに［取り消す］を出します（今の［🚶30分］と同じ動き）。
- 数える日数（30日）とボタンの数（2つ）は `lib/calorieConstants.ts` に置いてください。

## 5. トーストに「あと◯kcal」を添える
カードが画面の外にあっても、記録した手応えが伝わるようにします。メシため・うごためを保存したあと：
- まだの分が残っているとき：「🐷 メシため。あと15kcalです」「🏃 うごため 30分。あと15kcalです」
- その記録で、まだの分が0になったとき：今の「{チート名}、なかったことに。」のトースト
- 余りがあるとき：「🐷 メシため。チートにあと310kcal使えます」
- チートも予定もない月：「🐷 メシため。ビール1本ぶんです」（今の換算のまま）
- トーストは1つだけ。うごための［取り消す］は、どの文でも出します。
