## 3. 「◯月のチート」カード：同じ目盛りの棒を2本
### 形
```
11月のチート                            ›

食べた  🍺×1
[■■■■■■■■■■■■■■■■■■■■]  280kcal
貯めた  🐷×1
[■■■■■■■■■■□□□□□□□□□□]  150kcal

メシためあと1回で、なかったことにできます
```
- 2本の棒は**同じ目盛り**で描きます。いちばん右 ＝ 食べた分と貯めた分の大きいほう。長さを比べるだけで、どちらが多いかがわかるようにします。
- **食べた**の行：
  - その月のチートの絵文字（まとめ方は今と同じ。6個以上なら「🍺×13」のように1つ）。前月からの持ち越しがあれば、先頭に「先月の分」と添えます。
  - kcal は食べた分（持ち越しを含む）。
  - 棒の色は、なかったことにできた部分を amber-400、まだの部分を薄い amber にします（1本の中で、どこまでなかったことになったかもわかるように）。
- **貯めた**の行：
  - 「🐷×5 🏃×2」のように、その月のメシためとうごための回数。
  - kcal は貯めた分。棒の色は stone 系の明るい色（食べたの棒と区別できる色）。
- 数字は3けたごとにカンマを入れ、符号はつけません。
- v2.6 の、なかったことにできた割合を示す1本の棒はなくします。

### 状態ごとの一番下の行
- **A（まだの分がある）**：「メシためあと◯回で、なかったことにできます」（今のまま）
- **B（まだの分が0で、余りがある）**：
  - 食べた分が1以上なら「好きなものを食べながら、ちゃんと痩せてます」
  - 「チートにあと ◯kcal 使えます」と［今日食べる］［予定に入れる］（今のまま）
  - 食べた分が0のときは、食べたの行は棒を空にし、絵文字の代わりに「まだありません」と出します。
- **C（食べた分も貯めた分も0）**：棒は出さず、コンセプトの一文だけ（今のまま）。
- 予定の行（「28日の焼肉まで、メシためあと3回」など）はそのまま、棒の下に出します。

## 4. 持ち越し（期限をなくす）
- **貯めた分の余りは、これまでどおり翌月に持ち越しません。**
- **月末の時点でまだなかったことにできていないチートは、翌月にそのまま持ち越します。** 翌月の「食べた」に「先月の分」として入り、翌月1か月のあいだ（月末まで）、メシため・うごためで当てていけます。翌月7日の期限はなくします。
- **持ち越しのさらに持ち越しはしません。** 前月から持ち越した分が、その月の月末までに残っていても、翌々月には入れません。
  - 翌月に持ち越す量 ＝ その月のチート（持ち越しを除く）のうち、月末にまだの分。
  - 式：持ち越す量 ＝ max(0, その月のチート − max(0, その月の貯めた分 − 前月からの持ち越し))
  - なかったことにする順番は今のまま（持ち越し → 日付の早い順）。
- `lib/calorieConstants.ts` の持ち越しの期限（7日）の定数は削除してください。
- ログ：持ち越しがある月は、月の先頭の「先月の分 ◯kcal」の行を、月末まで出します（8日以降も消さない）。
- 体重など、ほかの計算への影響はありません。
