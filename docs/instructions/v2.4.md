## 14.1 呼び名：メシポ → チーぽ

- ポイントの名前を「メシポ」から「チーぽ」に変える（カタカナ＋ひらがな。「チーポ」ではない）
- 数字の単位は「pt」のまま（ボタンの「+150pt」など）。名前として出すところだけ「チーぽ」にする
  - 例：今週の内訳の見出し「今週貯まったチーぽ」、ログの合計「今月のチーぽ 1,050pt」
- 単位の使い分け：行動の結果（メシため・うごため）は pt、食べもの側（チート・ごほうび・ゼロカロ化）は kcal
- 「メシポ」で grep して画面の文言の漏れがないようにする。内部キー・変数名・DBの値は変えない

## 14.2 ごほうび（目標を超えて貯めた分）

### 定義
- ごほうび = 貯まったpt − 目標（0より大きいときだけ）。今月限りで、翌月には持ち越さない（今までどおり）
- チートを追加すれば目標が増えてごほうびは自然に減る。予約や「ごほうびで登録した」印などは作らない（DB変更なし）

### カードでの見せ方（今日の「◯月のメシため」カード）
- これまでの「あと◯kcal分、チートを追加できます」を、次の2行に置き換える
  - 「ごほうび 420kcal」
  - 「いまなら {品名} までいけます」
- {品名} は下の「ごほうび候補」の中から、kcal がごほうび以下でいちばん大きいもの1つ
- ごほうびが150kcal未満のときは「いまなら…」の行を出さない（「ごほうび ◯kcal」だけ）
- ゲージ：目盛りの最大を max(目標, 貯まったpt) にし、目標の位置から先（ごほうびの部分）は薄いアクセント色（amber-200 相当）で伸ばす
- 登録ボタンや「いつ使いますか？」のような呼びかけは置かない。チートのページにも出さない

### ごほうび候補（lib/rewardItems.ts を新設）
- 食べものの辞書（lib/foodItems.ts）の id を参照する。辞書にない品は辞書に追加する
- 並びは kcal の小さい順。たたき台（kcal はざっくりでよい）：

| kcal | 品名 |
|---|---|
| 150 | 高級アイス1個 |
| 200 | 生ビール中ジョッキ |
| 300 | ワイン2杯 |
| 400 | ショートケーキ |
| 500 | 特上にぎり1人前 |
| 650 | こってりラーメン |
| 800 | 特上カルビ定食 |
| 1000 | うな重（特上） |
| 1300 | ステーキ300g＋ライス |
| 1600 | 焼肉食べ放題 |

## 14.3 ログ（/log）

メシため・うごための記録を一覧で見て、直せるページ。ボトムナビは4タブのまま増やさない。

### 入口
- 今日のカードの内訳（タップで展開）の下に「記録を見る・直す」
- 「今週 +◯pt」の行を開いた内訳の下にも同じリンク

### 画面の構成（上から）
1. 「今月のチーぽ 1,050pt ≒ ビール◯杯ぶん」
   - 換算は辞書の「生ビール中ジョッキ」の kcal で割って切り捨て。1杯未満なら換算は出さない
2. 内訳の1行：「メシため◯回 ◯pt ・ うごため◯分 ◯pt」（歩数で記録したものは分に含めず、ptだけ足す）
3. 絞り込み：すべて／メシため／うごため（最初は「すべて」）
4. 過去14日分（今日を含む）の一覧。日ごとの見出し「11/10（火）」、新しい日が上
   - メシため：「朝　メシため　+150」
   - うごため：「うごため　ウォーキング30分　+150」（歩数なら「うごため　8,000歩　+280」）
   - 「いつもの」「がっつり」は一覧に出さない
   - 14日より前の記録は表示しない。記録がない日は見出しも出さない

### 直す
- 行をタップすると編集シート
  - メシため：「いつもの」「がっつり」に変える、または取り消す（取り消し＝未記録＝いつもの扱い）
  - うごため：種類・時間（または歩数）を変える、削除する
- 一覧に出ている過去14日分はすべて直せる（新しく記録できるのが過去7日まで、という今のルールは変えない）
- 直した結果、0kcal化済みだったチートが「まだ」に戻る場合も、メッセージは出さずに表示を静かに更新する
- 直した結果、新たに0kcal化済みになった場合は、13章のトースト「{チート名}、なかったことに。」を出してよい
- うごための削除にRLSの delete ポリシーが必要な場合は、既存のポリシーを確認し、足りなければマイグレーションSQL（何度実行しても大丈夫な書き方）を別ファイルで用意して知らせる

## 14.4 体重チャート：チートの累計（棒）＋体重（折れ線）

体重タブのチャートを、1つのグラフに「食べたチートの累計kcal（棒）」と「体重のならした線（折れ線）」を重ねた形にする。

### 見出し
- 左：「11月に食べたチート」（はじめてからの表示では「はじめてから食べたチート」）、右：累計 kcal（例「3,800kcal」、アクセント色）
  - 「実質0kcal」とは書かない（0kcal化されていないチートも含むため）
- 線の右端の下に体重の変化：「体重 1.2kg減」／「変わらず」／「0.2kg増」（13章の月初めからの体重変化と同じ考え方。期間を引数で渡せる純粋関数にする）

### 棒（後ろ）
- 日ごとの棒で、高さ = その日までに食べたチートのコストの累計（階段状に上がる）
- 数えるもの：日付のあるチートとがっつりを、その日付に。今日より先の日付のチートは数えない
- 日付のないチート（週◯回）は棒には入れず、見出しの累計kcalにだけ含める
- 色は薄いアクセント色（amber-200 相当、半透明）。縦の目盛りは出さない
- チートを食べた日の棒の上に、そのチートの絵文字（がっつりは🔥）。タップで品名とkcal

### 折れ線（前）
- 今の「ならした線」と体重の点をそのまま使い、濃い色で棒の前に描く。縦の目盛りは出さない
- 体重の縦の範囲は固定の幅にする：期間の最初のならした値を中心に ±2kg。外れる値があるときだけ、収まるように広げる（見た目で減少を大げさにしないため）

### 期間の切り替え
- 「今月／はじめてから」の切り替え（最初は「今月」）
- はじめてから：棒は週ごと（その週の終わりまでの累計）、体重も週ごとにまとめる
- 今のチャートの描き方（ライブラリ）をそのまま使う。新しいライブラリが必要な場合は理由を添えて確認を取る

## 14.5 変えないもの

- pt の値、目標の計算、毎日の目安の計算、新しく記録できる日の範囲（過去7日）
- DBの列名・保存値（マイグレーションは 14.3 の delete ポリシーが必要な場合だけ）
