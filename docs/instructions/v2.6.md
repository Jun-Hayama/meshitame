## 1. ねらい
- 実際に使ってみると、チートは前もって決めるより、当日に「今日は飲みたい」と足すことがほとんどでした。それに合わせて考え方を変えます。
- **新しいコンセプト：「飲みたい日は飲む。そのぶんは、メシためでなかったことに。」**
  - メシため・うごためは、食べる前でも後でも効きます。
  - 先に貯めておけば、急に飲みたくなっても大丈夫。
  - 予定があるもの（飲み会など）だけ、前もってカレンダーに入れます。
- あわせて、初めての人が説明なしで使えるよう、言葉と画面を整理します。

## 2. 言葉をそろえる
- **単位は kcal だけにします。** チーぽ・pt は画面からなくします（1pt＝1kcal なので計算は変わりません）。
- 画面から消す言葉：チーぽ、pt、ごほうび、ペースの目印、置き換え、上乗せ、0kcal化、ゼロカロ化、ためメシ（残っていれば）、月の「目標」
- 言い換える言葉：ゲート → **目標体重**（初回設定・設定・体重タブのすべて）
- 運動のボタンは「🏃＋うごため」（呼び名のうごためはそのまま）
- 画面の文言はすべて、下の10章「日本語の書き方」に従ってください。
- コードの中の名前（DBの列名、型名、内部キー）は変えなくてかまいません。

## 3. 今日の画面
### 3-1. 食事の記録
```
朝   🐷メシため  🍚いつもの  🔥チート
昼   🐷メシため  🍚いつもの  🔥チート
夜   🐷メシため  🍚いつもの  🔥チート

食事のほかに  🍺×2  🍰ケーキ          ＋
🏃＋うごため
```
- 3択の3つ目は「🔥チート」（内部はこれまでの がっつり）。
  - 押すと「何を食べた？」の画面を出します。品と数量を選べますが、**選ばずに保存してもOK**（そのときはこれまでのがっつりと同じ300kcal）。
  - 保存のしかた：食事の記録は内部の がっつり として保存します。品を選んだときは、あわせて同じ日・同じ食事のチートとして保存します（コスト＝合計 − その食事の目安、下限0。これまでの置き換えと同じ）。品つきのチートがある食事では、がっつりの300は数えません（これまでのルールどおり）。
  - 画面の見出しは「夜ごはんをチートに」（朝・昼も同じ形）。その下に小さく「いつもの食事との差だけ数えます」と添えます。
  - チートが入っている食事の行は、🔥チートが選ばれた状態で、横に品の絵文字を小さく出します（例：🔥チート 🍜🍺）。押すと変更・取り消し。
- 行に🔥チートが選ばれた状態になるのは、その食事に がっつり の記録があるか、その食事のチートがあるときです。
- カレンダー（チートのタブ）で日付と食事を決めて入れたチートは、その日のその行に最初から入っています。
- 書き換え：チートが入っている行で🐷メシためか🍚いつものを押したら、「{チート名}を取り消しますか？」と確かめてから、その食事のチートと がっつり の記録を消し、押したほうで記録します。
- **「食事のほかに」**の行：食事とは別に食べたもの・飲んだもの（お菓子、2軒目、晩酌など）を、その日の分すべて並べます。
  - 「＋」で追加。コストは合計そのまま（これまでの上乗せと同じ）。画面の見出しは「食事のほかにチートを足す」。その下に小さく「食べた分をそのまま数えます」と添えます。
- 呼び名はどちらも「チート」のままにし、新しい言葉は足しません。違いは、足す場所と追加画面の見出しで伝えます。
  - 何もない日は「食事のほかに」と「＋」だけを出します。
- 置き換え／上乗せを選ぶ画面はなくします。**どこから足したか**で数え方を決めます。
- チートを足す画面では、品の一覧の上に**よく食べるもの**を最大6つ並べ、1タップで選べるようにします（直近60日に記録した回数の多い順。頻度ベースで登録済みの品も入れる）。数量は ＋／− だけ。

### 3-2. 「◯月のチート」カード
これまでの「◯月のメシため」カードを置き換えます。カードの中にボタンは置きません。**カード全体を押すとログ（/log）へ**行きます。見出しの右に「›」をつけます。

状態は3つ。計算はすべて 5章の関数で行います。

**A. まだなかったことにできていない分があるとき**
```
11月のチート                            ›
🍺×3 🍜×1
[■■■■■■■■■■■■■■■□□□□□]
メシためあと3回で、なかったことにできます
```
- 1行目：まだの分になっているチートの絵文字（まとめ方は今のゲージと同じ。6個以上なら「🍺×13」のように1つ）。前月からの持ち越しがあれば、先頭に「先月の分」と添える。
- 棒：食べた分のうち、なかったことにできた割合。
- 回数 ＝ まだの分 ÷ 150 の切り上げ。

**B. 食べた分をぜんぶなかったことにできていて、余りがあるとき**
```
11月のチート                            ›
好きなものを食べながら、ちゃんと痩せてます
チートにあと 460kcal 使えます
[ 今日食べる ]  [ 予定に入れる ]
```
- 1行目は、その月に食べた分が1つ以上あるときだけ出します。
- 「今日食べる」→ 今日の「食事のほかに」の追加画面へ。「予定に入れる」→ チートのタブの追加画面へ。

**C. 食べた分も余りもないとき（月の初めなど）**
```
11月のチート                            ›
飲みたい日は飲む。そのぶんは、メシためでなかったことに。
```

**予定の行（A・B・C 共通）**：今月の、今日より後の日付のチートがあれば、いちばん近いものを1行出します（余りは翌月に持ち越さないので、翌月の予定はここに出しません）。
- 余りで足りていれば「28日の焼肉は、もう準備OK」
- 足りなければ「28日の焼肉まで、メシためあと3回」（回数 ＝ その予定までに足りない分 ÷ 150 の切り上げ）

### 3-3. カードから外すもの
- 「これだけ食べて、月初めから変わらず」の行 → 体重タブの記録カードの下へ移す（文言はそのまま）。
- 今週の行（「今週は+1950pt！…」）→ ログの先頭へ移す（6章）。
- ゲージの絵文字のチップ、目標の先を薄い色で伸ばす表示、ごほうびの行 → なくす。
- 「チートの一覧・編集」のリンク → なくす（チートのタブと同じなので）。

### 3-4. トースト
- メシため：「🐷 メシため。ビール1杯ぶんです」のように、150kcal を身近な品で言い換えます（今のビール換算を使う）。
- うごため：「🏃 うごため 30分。◯◯ぶんです」。
- チートがなかったことになったとき：「{チート名}、なかったことに。」（今のまま）
- 符号つきの数字（+150 など）はトーストに出しません。

## 4. チートのタブ（カレンダー）
- 「予定に入れる」の画面：日付（今日以降）・食事（朝／昼／夜／食事のほかに）・品と数量。
- 一覧は日付順。今日より前のものは「食べた」、後のものは「予定」として分けて見せます。
- **頻度ベース（週◯回）の登録はなくします。** 新しく作れないようにし、登録済みのものはコストに数えず、「よく食べるもの」の候補としてだけ使います。チートのタブにあれば「よく食べるもの」として表示し、削除できるようにします。
- DB：チートに「どの食事か（朝／昼／夜／食事のほかに）」を持つ列がなければ、`migration_v2_6_cheat_meal.sql` で追加してください（null は「食事のほかに」として扱う。RLS・grant はこれまでどおり。何度実行しても大丈夫な書き方で）。既存の置き換えチートは、持っている食事の情報をそのまま使い、上乗せチートは「食事のほかに」として扱います。

## 5. 計算（lib/calories.ts の純粋関数＋テスト）
- **貯めた分**（月）＝ メシため×150 ＋ うごための kcal（これまでの貯まったpt と同じ）
- **食べた分**（月・今日まで）＝ 次の合計
  - 前月からの持ち越し（下記）
  - その月の今日までの日付のチート（食事のチートは 合計 − その食事の目安、下限0。食事のほかには合計そのまま）
  - 品を選ばなかった🔥チート × 300（その食事に品つきのチートがあるときは数えない。これまでのルールどおり）
- **なかったことにする順番**：持ち越し → 日付の早い順（同じ日なら朝・昼・夜・食事のほかにの順）。貯めた分を先頭から当てていき、全額に届いたものを「なかったことに」とします（これまでの0kcal化済みと同じ考え方）。
- **まだの分** ＝ max(0, 食べた分 − 貯めた分)
- **余り** ＝ max(0, 貯めた分 − 食べた分)
- **予定の準備**：今月の、今日より後の予定を日付順に並べ、余りを当てていく。翌月の予定は対象にしない。足りていれば準備OK、足りなければ足りない分。
- **持ち越し**：月末の時点のまだの分を、翌月に持ち越します。翌月7日までのメシため・うごためで当てていき、**7日が終わった時点で残っていた分は消します**（翌月8日以降は数えない。画面でも触れない）。持ち越しのさらに持ち越しはしません。余りは持ち越しません。
- **順調**（内部の判定）＝ 今日までの食べた分が1以上あり、まだの分が0。v2.5 で「順調」を使っている箇所（体重のトーストなど）は、この新しい判定に置き換えてください。ペースの目印の計算は使わなくなるので、参照がなくなれば削除してください。
- **食事になる品**：アイテム表から食事のチートとして選ぶか、食事のほかにとして選ぶかは、足した場所で決まります。品の側に区別は持ちません。

## 6. ログ（/log）
- 先頭に今週の行：「今週は 1,950kcal 貯まりました。飲み会1回ぶんです🍻」（今の文言の考え方のまま、pt を kcal にし、符号を外す）。押すと内訳（これまでの今週の内訳）。
- 今月の合計の見出しも kcal にそろえます。
- 一覧の各行も符号をつけずに出します（「🐷 メシため 夜 150kcal」「🍺 チート 夜 ビール×2 280kcal」）。
- 持ち越しがある月は、月の先頭に「先月の分 ◯kcal」の行を出します（8日以降は出さない）。

## 9. テスト（lib/calories.test.ts）
- 食べた分：食事のチート（差分・下限0）／食事のほかに（そのまま）／品なしの🔥チート（300）／同じ食事に品つきのチートがあれば🔥を数えない／今日の予定のチートは数える・明日以降は数えない
- なかったことにする順番：持ち越しが先、日付順、同じ日は朝→昼→夜→食事のほかに
- まだの分・余り・メシための回数（切り上げ）
- 予定の準備：余りで足りる／足りない（回数）／予定が複数／翌月の予定は対象にしない
- 持ち越し：月末のまだの分が翌月に入る／7日までに当てた分が消える／8日以降は数えない／余りは持ち越さない
- 順調：食べた分0のときは順調にしない／まだの分0で順調
- カードの状態 A／B／C の判定
- 頻度ベースのチートはコストに数えない
- 既存のテストで pt・目標・ペースの目印を前提にしたものは、新しい計算に合わせて直してください。

## 10. 日本語の書き方（CLAUDE.md にも追記）
- 英語の直訳のような言い回しにしない。友だちに話すときの自然な日本語で書く。迷ったら声に出して読む
- 硬い言葉より、ふだん使う言葉を選ぶ（「見込み」→「〜そう」、「水分中」→「むくみ中」）
- 予測は言い切らない。「〜そう」「〜かもしれません」を使う
- 回りくどい言い方をしない（「〜することができます」→「〜できます」、「〜を行う」→「〜する」）
- 「あなた」と呼びかけない
- 文中の日付は「26日」。月をまたぐときだけ「12月2日」。「11/26」の形は文中に出さない（グラフの目盛りなどは可）
- 画面はやわらかい「です・ます」が基本。短い一言は「なかったことに。」のような言い切りや体言止めでもよい
- ボタンは短く、何が起きるかわかる言葉にする
- 新しい造語は増やさない
- マイナスの数字、「食べすぎ」「我慢」「禁止」は出さない
