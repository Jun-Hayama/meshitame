## 1. ねらい
- 貯めた分がチートを超えたとき、わざわざ食べるようにすすめる必要はない。「ぜんぶなかったことにできた」ことを伝えるだけにする
- 今日の記録の小見出しを、行動の名前「メシため」「うごため」にして、開いた瞬間から「軽めにする・動くと、好きなものが食べられる」と伝える
- うごためのボタンに、何の運動なのかがわかる名前を出す

## 2. カード：「使える」の促しをなくす
- 貯めた分がチート以上のとき（今の「チートにあと◯kcal使えます」の状態）：
  - 「チートにあと◯kcal使えます」の行と、［今日食べる］［予定に入れる］のボタンをなくします。
  - 代わりに、チートが1以上なら「ぜんぶ、なかったことに。」を1行（amber）出します。
  - 棒の縦線と、その先の淡い色の部分は今のまま残します（貯めた分のほうが多かったことは、棒で伝わるため）。
- チートが0で貯めた分だけあるとき：棒は今のまま。一番下の行は出しません。
- 予定の行（「28日の焼肉まで、あと◯kcal」「もう準備OK」）は今のまま出します。
- 「今日食べる」「予定に入れる」のためだけにある処理（`?add=1` へのリンクなど）は、ほかで使っていなければ消してください。チートのタブの「予定に入れる」の画面そのものは残します。

## 3. トースト：「使える」をなくす
v2.6.3 のトーストの e（それ以外）を変えます。
- e：今月のチートがぜんぶなかったことになっているとき →「🐷 メシため。今月のチートは、ぜんぶなかったことに。」（うごためも同じ形）
- a〜d は今のまま。

## 4. 今日の記録の小見出し
```
今日の記録                              ［目安］

🐷 メシため  軽めにすると150kcal
朝   🐷メシため  🍚いつもの  🔥チート
昼   🐷メシため  🍚いつもの  🔥チート
夜   🐷メシため  🍚いつもの  🔥チート
追加チート  おやつ・お酒・2軒目など        ＋

🏃 うごため  意識して動いた分
［🚶 ウォーキング 45分］［🏋️ 筋トレ 30分］［＋うごため］
```
- 「ごはん」→「🐷 メシため」、「うごき」→「🏃 うごため」に変えます。
- 小見出しの右に、小さく薄い文字で一言を添えます。
  - メシため：「軽めにすると150kcal」（数字は定数から）
  - うごため：「意識して動いた分」
- 「今日は 🚶30分・👣8,000歩」の行は今のまま、うごための小見出しの下に出します。

## 5. うごためのボタンに中身を出す
- ボタンの表示を「🚶 ウォーキング 45分」のように、**絵文字・種類の名前・分**にします。kcal はボタンからは外します（保存したときのトーストで伝わるため）。
- 種類の名前は、うごための画面で使っている名前と同じにします。
- **同じ種類のボタンが2つ並ばないようにします。**
  - 直近30日のうごための記録（歩数は除く）を**種類ごと**に数え、回数の多い種類から2つ選びます（同じ回数なら、最後に記録した日が新しいほうを先に）。
  - それぞれの種類の分数は、その種類で直近30日にいちばん多く記録した分数にします（同じ回数なら新しいほう）。
  - 2つに足りないときは、ウォーキング30分、ランニング30分の順で埋めます。ただし、すでに出ている種類は飛ばします。
- ボタンを押したときの動き（その場で保存、トーストに［取り消す］）は今のままです。
