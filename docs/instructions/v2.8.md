## 1. 考え方
- **勝ち負けはつけません。励まし合うことに徹します。** 順位やランキングは作りません。
- 目標体重や期間は人それぞれでかまいません。見せ合うのは「頑張っていること」と「好きなものを食べながら、目標体重に近づいていること」です。
- いちばんの励みは**「一緒に食べる約束」**です。友だちと「20日 焼肉」のような約束を決めて、その日に向けてそれぞれメシためを貯めます。
- **体重の数字（kg）は相手に一切見せません。** 画面だけでなく、DBの権限でも友だちから読めないようにします。

## 2. 今回やること・やらないこと
- **今回（v2.8）**：名前とキャラクター、友だちの招待、一緒に食べる約束（約束の誘い＝友だちの招待）、すごろくコース（見るだけ）、約束までの準備の具合、チートの中身を隠す設定、今日の画面のカード
- **次回（v2.9）**：お知らせ、いいね、うらやましい、未読のバッジ、みんなの合計。今回はこれらのテーブルや画面を作らないでください。
- ボトムナビは4タブのままです。

## 3. 画面
- **今日の画面**：今日の記録（メシため・うごため）の下にフレンドカードを1枚置きます。押すと `/friends` へ。
  - 友だちも約束もない：「友だちと食べる約束をする」ボタンだけ
  - 友だちがいる：小さなコース（自分と友だち）
  - 約束がある：いちばん近い約束を1行（「🍖 20日の焼肉まで、あと27日」）と、参加者のキャラクターと準備の具合
  - 約束の当日：「🍖 今日は焼肉の日」
- **/friends**：これからの約束、コース、友だちの一覧（招待・やめる）、自分の名前とキャラクター、隠す設定
- **/friends/promise/new**：約束を作る
- **/friends/join/[token]**：誘いのリンクを開いたページ

## 4. 名前とキャラクター
- `/friends` を初めて開いたとき、または招待・約束を作る前に、まだ決めていなければ表示名とキャラクターを決めてもらいます。**決めるまで招待のリンクは作れません**（相手に名前が出せないため）。
- 表示名は1〜12文字。あとから変えられます。
- キャラクターは 🐷 🐔 🐮 🐻 🐱 🐶 から選びます（初期値は🐷）。

## 5. 一緒に食べる約束
### 作る
- 決めること：
  - 日付：明日から60日以内（貯めた分の余りは翌月に持ち越さないので、遠すぎる約束は作れないようにする）
  - 食事：昼／夜／追加チート（初期値は夜）
  - 何を食べるか：アイテム表から品と数量、または自由入力の名前
  - 場所：なくてもよい。30文字まで
- 何を食べるかを選ぶ画面は、既存の `CheatItemPicker`（予定に入れるときの使い方）を使ってください。
- 作ると、作った人の**予定のチート**として自動で入ります。保存のしかたはチートのタブの「予定に入れる」と同じにします（`monthly_wants` に保存し、食事が昼・夜のときは `meal_logs` にもその日・その食事の hearty を保存する。`app/wants/page.tsx` の `handlePlanned` と同じ形）。
- 作ったあと、誘いのリンクを Web Share API で送れます（使えなければコピー）。

### 参加する（/friends/join/[token]）
- まず、トークンから「誘った人の名前とキャラクター」「約束の日付・食べるもの・場所」「状態」を表示します（ログイン前でも読める、見せてよい値だけを返す関数で）。
- ログイン済みなら「🐷◯◯さんの『20日の焼肉』に参加しますか？」→ OK で：
  - 約束の参加者になる
  - 誘った人とまだ友だちでなければ、友だちになる
  - 自分の予定のチートとして、同じ日付・食事・品で自動で入る（保存のしかたは作るときと同じ。食事が昼・夜なら hearty も）
  - 名前とキャラクターをまだ決めていなければ、先に決めてもらう
- 未ログインなら、トークンを端末に保存してからログイン（または登録）へ進み、ログイン後にこのページへ戻します。メール確認つきの登録でも戻れるよう、保存したトークンで戻してください。戻り先は `/friends/join/` で始まるパスだけを許可します。
- 次の場合は、それぞれわかる言葉で知らせてください：自分の誘い、期限切れ、止められたリンク、取りやめになった約束、約束の日が過ぎた、定員（作った人を含めて6人）、友だちの上限（10人）、すでに参加している。

### 取りやめ・抜ける
- 作った人は「取りやめ」ができます（確認つき）。日付を変えたいときは、取りやめて作り直します。
- 参加者は「抜ける」ができます（確認つき）。作った人は抜けられません（取りやめになります）。
- 取りやめたり抜けたりしたあとも、各自の予定のチートは残します（「予定のチートはそのまま残ります。チートのタブで消せます。」と添える）。チートのタブで消したときは、今のしくみどおり hearty も一緒に消えます。

### 約束までの準備の具合（lib/calories.ts の純粋関数＋テスト）
- 参加者ごとに、約束のチートが**どこまで準備できているか（0〜100%）**を出します。v2.6 の「予定の準備」（`calcMonthCheatStatus` で、余りを今月の予定に日付順に当てていく計算）と同じ考え方で、その約束に当たった分の割合です。
- 約束の月がまだ始まっていなければ、%は出さずに「12月に入ったら貯めはじめ」と出します。
- 表示：参加者ごとにキャラクター・名前・小さな棒と%。100%なら「準備OK」。
- 全員が100%なら、約束の行に「みんな準備OK」と出します。
- 約束の日を過ぎたものは「これまでの約束」に移し、30日たったら一覧から隠します。

## 6. 友だちの招待（約束なし）
- 約束を作らずに「友だちを招待」もできます。仕組みは約束の誘いと同じで、約束の部分がないだけです（参加すると友だちになる）。
- 招待のリンクの有効期限は7日。約束の誘いは「7日後」と「約束の日の前日」の早いほうまで。期限内は複数の人が使えます。作った人は「リンクを止める」ができます。
- 友だちは10人まで。友だちの一覧から「友だちをやめる」ができます（確認つき。双方から消える）。友だちをやめても、一緒に参加している約束からは抜けません。

## 7. すごろくコース
### 目標体重への近づき具合（lib/calories.ts の純粋関数＋テスト）
- 近づき具合(%) =（始めた体重 − いまの体重）÷（始めた体重 − 目標体重）× 100。0〜100に収め、整数に丸めます。
  - 始めた体重：最初に体重を記録した日の体重（v2.4 の「はじめてから」と同じ起点）
  - いまの体重：ならした体重（体重チャートの線と同じ計算）
  - 目標体重が未設定、または始めた体重 ≦ 目標体重なら、コースには置かずに名前だけ出します（約束には参加できます）。
- **むくみ中**：v2.7 の戻り期間中で、最新の体重（チート後の記録）が基準＋0.3kg以上なら、
  - 近づき具合は、まとまりの最初の日の前日の値で止めます（チートで後ろに下がって見えないように）。
  - 名前の横に「🍜むくみ中・26日ごろ戻りそう」と出します（絵文字はそのチートの品、品が2つ以上か品なしの🔥チートなら🔥）。
- **ちょっと寄り道中**：むくみ中でなく、7日前の近づき具合より下がっていたら、名前の横に「ちょっと寄り道中」と出します。

### 道と足あと（まずは絵文字で）
- 横一本の道で、1人1レーン。左がスタート、右端がゴール（🏁🍖）。いちばん上が自分です。
- 各人のキャラクターを近づき具合の位置に置きます。
- 各レーンの下に1行：「🍺×12 🍜×3 食べて、目標体重まで45%」
  - 数えるのは、始めた日から今日までのチートの品の**数量**と、品なしの🔥チートの回数（🔥）。多い順に3種類まで。予定のチートは数えません。
- **チートの足あと**：
  - そのチートを食べた日の近づき具合の位置に、品の絵文字を置きます（品なしの🔥チートは🔥）。
  - 同じ位置に重なるものは「🍺×3」のようにまとめます。新しいものから30個まで。
  - 3つの見え方（判定は v2.6・v2.6.1 の「なかったことにする順番」と持ち越しのルールを、その月ごとに使う）：
    - なかったことにしたもの → 色つき
    - まだのもの（今月の分と、先月からの持ち越し） → 薄く
    - 持ち越した月の月末までになかったことにできず、消えたもの → ふつうの色（薄くしない。過ぎたことは責めない）
  - 今回は押しても何も起きません（うらやましいは v2.9）。

## 8. チートの中身を隠す設定
- `/friends` に「チートの中身を友だちに見せない」を1つ置きます（初期値はオフ）。
- オンのとき、友だちに書き出す足あと・チートの数の集計・むくみ中の絵文字を、すべて🍽に置き換えます（「🍽×15 食べて、目標体重まで45%」）。置き換えは書き出す前に本人の画面で行い、DBにも中身を残さないでください。
- 約束の食べものは、参加者どうしで決めたものなので隠しません。

## 9. データの持ち方
既存テーブルのRLS（自分の行だけ）は変えません。既存テーブルに列も足しません。友だちに見せるのは、**見せてよい値だけを書き出した公開用のテーブル**からだけにします。

| テーブル | 中身 | 書ける人 | 読める人 |
|---|---|---|---|
| friend_profiles | 表示名、キャラクター、隠す設定、更新日時 | 本人 | 本人、友だち、同じ約束の参加者 |
| friend_progress | 近づき具合（null＝目標体重なし）、寄り道中か、むくみ中（絵文字と戻りそうな日、またはnull）、足あと、チートの数の集計、更新日時。**kgは入れない** | 本人 | 本人と友だち |
| friend_invites | 作った人、トークン、約束（nullなら友だちの招待だけ）、期限、止めた日時 | 関数経由のみ | 作った人 |
| friendships | 自分、友だち（両方向の2行で持つ） | 関数経由のみ | 本人 |
| promises | 作った人、日付、食事、食べもの（アイテムのidと数量、または自由入力の名前）、場所、状態（active / canceled）、作成日時 | 関数経由のみ | 参加者 |
| promise_members | 約束、参加者、参加日時、準備の具合(%)（nullなら月がまだ）、更新日時、自分のチートのid | 参加・抜けるは関数経由。準備の具合・更新日時・チートのidは本人が更新 | 同じ約束の参加者 |

- 判定用の関数：`is_friend(uid)`、`is_promise_member(promise_id)`。RLSのポリシーが自分のテーブルを参照して無限ループにならないよう、`security definer` で作ってください。
- `security definer` の関数（期限・止めたリンク・自分自身・取りやめ・約束の日・定員6人・友だち10人（双方）・重複をチェック）：
  - 約束を作る（作った人を参加者に入れる）
  - 招待を作る・止める
  - 招待の中身を見る（誘った人の表示名・キャラクター、約束の日付・食事・食べもの・場所、状態だけを返す。anon からも呼べる）
  - 招待で参加する
  - 約束を取りやめる・抜ける
  - 友だちをやめる
- `promise_members` の本人による更新は、準備の具合・更新日時・チートのidの列だけに grant を絞ってください。
- `friend_progress` と自分の `promise_members` の準備の具合は、本人の画面で計算して書き出します。タイミングは、今日の画面を開いたとき（前回の更新から1時間以上たっていれば）、体重の保存、メシため・うごため・チートの記録と取り消しのあとです。
- マイグレーションは `migration_v2_8_friends.sql` にまとめてください。RLS、authenticated への grant（招待の中身を見る関数だけ anon にも）、何度実行しても大丈夫な書き方で。

## 10. 言葉のルール
- `CLAUDE.md` の「日本語の書き方」に従う。
- 相手の体重・kg・減った量は出さない。
- 「負け」「遅れ」「順位」「食べすぎ」「我慢」「禁止」は使わない。下がったときも責めない（「ちょっと寄り道中」「むくみ中」）。
- 記録していない友だちについて、何も出さない（「◯日記録なし」などは出さない）。
- マイナスの数字は出さない。

## 11. テスト（lib/calories.test.ts）
- 近づき具合：通常、0未満と100超の丸め、目標体重なし
- むくみ中：戻り期間中は位置を止める／期間を過ぎたら通常／むくみ中のときは寄り道中を出さない
- 寄り道中の判定
- 足あとのまとめ：同じ位置の集約、30個まで、3つの見え方（色つき・薄い・ふつう）、持ち越しは1か月まで
- チートの数の集計：数量で数える、品なしの🔥は回数、多い順に3種類、予定は数えない
- 約束の準備の具合：予定の準備と同じ計算／月がまだならnull／全員100%
- 隠す設定：足あと・集計・むくみ中の絵文字が🍽に置き換わる
- 約束の日付：明日から60日以内だけ
