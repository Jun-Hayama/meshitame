## 1. ねらい
チートのあとに体重が1〜2kg増えるのは、ほとんどが糖質と塩分にともなう水分で、脂肪ではありません。
「何kg増えるか」を当てることより、**「いつごろ戻るか」を日付で見せて、「メシためはちゃんと効いてる」と安心してもらうこと**を優先します。
判定はアイテム表の印と決まったルールだけで行い、AIは使いません。

## 2. 「むくみやすい」印
- `lib/foodItems.ts` の型に `waterHeavy?: boolean` を足し、糖質か塩分が多い品につけてください。
  - つける例：ラーメン・つけ麺などの麺類、丼もの、カレー、寿司、ピザ、ケーキ・和菓子などの甘いもの、焼肉・焼き鳥（タレ）、揚げ物、ポテトチップスなどしょっぱいおつまみ、ビール・日本酒・サワーなど糖質の多いお酒
  - つけない例：ハイボール・焼酎・ワイン、ステーキ、刺身、サラダ
  - 迷うものは、糖質か塩分が多ければつけてください。
- 実装後に、印をつけた品・つけなかった品を表で報告してください。

## 3. 判定（lib/calories.ts の純粋関数＋テスト）
- **むくみやすい日**：その日に次のどれかがある日
  - 印つきの品を1つ以上含むチート（食事のチートでも、追加チートでも）
  - 自由入力のチート（中身がわからないので印つきとして扱う）
  - 品を選ばなかった🔥チート（品つきのチートがある食事の がっつり の記録は、品なしとして扱わない。v2.6 の保存のしかたに合わせる）
  - 予定のチートは、その日が来るまで数えません。
  - チートを取り消したり書き換えたりしたら、判定もそれに合わせて変わります（保存した結果から毎回計算する）。
- **まとまり**：むくみやすい日が続いているとき（あいだが空いていない連続した日）は、ひとまとまりとして扱います。1日だけならその1日がまとまりです。以下の「最初の日」「最後の日」は、直近のまとまりのものです。
- **基準の体重**：まとまりの**最初の日の前日まで**の7日平均（既存の7日平均の関数を使う）。前のチートの水分が基準に入らないようにするためです。記録が3件未満なら基準なしとし、体重を比べる表示はすべて出しません。
- **何日目**：まとまりの最後の日の翌日を1日目と数えます。
- **戻り期間**：1日目から3日目まで。
- **戻りそうな日**：最後の日の3日後（＝3日目）。
- **チート後の記録**：まとまりの最初の日以降の記録だけを使います。それより前の記録は「前回の記録」「最新の体重」に使いません。
- 「順調」は v2.6 の判定（今日までの食べた分が1以上あり、まだの分が0）を使います。`calcMonthCheatStatus` の `onTrack` をそのまま使ってください。
- 品の絵文字は既存の `getCheatEmoji` を使ってください。
- v2.8 のフレンドでもこの判定を使うので、「直近のまとまり・何日目・戻りそうな日・基準」をまとめて返す関数にしてください。

## 4. 今日の画面
- 表示中の日付が今日で、今日がむくみやすい日なら、「◯月のチート」カードの下（カードの枠の外）に1行足します。小さめの文字で、カードと今日の記録のあいだに置きます。
  - 「明日は1〜2kg増えるかもしれません。水分なので、{日付}ごろには戻りそうです。」
  - {日付} は今日＋3日。
- 過去の日付を表示しているときは出しません。

## 5. 体重を保存した直後のトースト
保存した記録の日付が1〜5日目のときだけ判定します。上から順に見て、最初に当てはまったものを1つだけ出してください。

1. **戻った**：前回の記録（チート後の記録のうち、今回より前で最後のもの）が基準＋0.3kg以上で、今回が基準＋0.2kg以下
   - 「もとに戻りました。メシためはちゃんと効いてます。」
2. **増えている**（1〜3日目のみ）：今回が基準＋0.3kg以上
   - まとまりが2日以上、かつ順調 →「水分が続いているだけです。{日付}ごろには戻りそうです。」
   - 順調 →「増えたのは水分です。{日付}ごろには戻りそう。好きなものを食べながら、ちゃんと痩せてます。」
   - 順調でない →「増えたのは水分です。{日付}ごろには戻りそう。あと{N}kcalで、なかったことにできます。」
     - N ＝ まだの分（カードの「あと◯kcal」と同じ値）。
   - 順調のときの文の後半は、定数 `CHEAT_CARD_ON_TRACK`（「好きなものを食べながら、ちゃんと痩せてます」）を使います。
- {日付} は戻りそうな日。
- 4〜5日目で戻っていないときは、新しいトーストは出しません（戻りそうな日を過ぎたら、その話はしない）。
- このトーストが出るときは、v2.5 の水分のトーストは出しません（1回の保存でトーストは1つだけ）。
- 体重の保存は、今日の画面の「今朝」の入力からも、体重タブからもできます。どちらから保存しても同じトーストを出してください。
- どれにも当てはまらなければ、v2.5 のルールのままです（「順調」は v2.6 の判定）。

## 6. 体重タブ
- 戻り期間中で、最新の体重（チート後の記録）が基準＋0.3kg以上なら、記録カード（`WeightEntryCard`）の下に1行出します。v2.6 で移した「これだけ食べて、月初めから…」の行があるときは、その下に置きます。
  - 「{チート名}から{N}日目。{日付}ごろには戻りそうです。」
  - チート名は、まとまりの最後の日のものから決めます。数えるのは、その日をむくみやすい日にしたもの（印つきのチート・自由入力のチート・品なしの🔥チート）だけです。
    - 品が1つ → その品の名前（「ラーメン」）
    - 品が2つ以上 →「チート」
    - 品なしの🔥チートだけ →「チート」
- 戻り期間を過ぎたら、この行は出しません。
- チャート：
  - むくみやすい日に、その日のチートの絵文字を1つ小さく置いてください（品なしの🔥チートは🔥）。
  - 日ごとの体重を小さな点で出してください（ならした線はそのまま）。すでに出ていれば変更不要です。
  - 戻り期間中だけ、戻りそうな日に薄い目印（細い縦線など）を置いてください。
