## 2. 「◯月のチート」カード
### 形（まだの分があるとき）
```
11月のチート                              ›
ビール約28杯ぶん食べて、月初めから0.4kg減

チート                           5,670kcal
[■■■■■■■■■■■■■■■■■■■■■■■■■■▨▨▨]
貯めた  🐷22回 🏃9回    5,535kcal  あと135kcal

あと135kcalで、なかったことにできます
🚶 30分歩けば届きます              ［記録する］
                                     ヒント ›
```
### 形（貯めた分がチートを超えたとき）
```
11月のチート                              ›
ビール約28杯ぶん食べて、月初めから0.4kg減

チート                           5,670kcal
[■■■■■■■■■■■■■■■■■■■■■■■■■■■│■■■]
貯めた  🐷24回 🏃10回                6,000kcal

チートにあと 330kcal 使えます
［今日食べる］ ［予定に入れる］
```

### 決まりごと
- **見出しの下の1行（換算と体重）**
  - その月のチートの合計kcalを、**その月にいちばん多く（kcalで）食べた品**に換算します：「ビール約28杯ぶん食べて」。数は四捨五入した整数に「約」をつけます。品がない（品なしの🔥チートだけ）ときは、ラーメンで換算します。換算の単位は `lib/foodItems.ts` の単位を使います。
  - 体重の部分は、v2.3 の「月初めから」の計算を使います。
    - 減っていれば「、月初めから0.4kg減」
    - 変わらずなら「、体重はそのまま」
    - 増えているとき、または計算できないときは、体重の部分は出さず「ビール約28杯ぶん食べました」
  - チートが0のときは、この行を出しません。
- **棒は1本**
  - 「チート」の行：ラベルと合計kcalだけ。絵文字は出しません（中身はログで見る）。
  - 棒の全体の長さ ＝ チートと貯めた分の大きいほう。
  - 貯めた分を amber-400 で塗ります。
  - **足りない部分**（貯めた分 < チート）：斜線の amber（または薄い amber に濃い縁取り）にして、**どんなに小さくても棒の幅の8%以上**で描きます。棒の下、足りない部分の位置に「あと135kcal」と書きます。
  - **超えた部分**（貯めた分 > チート）：チートの位置に細い縦線を入れ、そこから先を別の色（明るい stone か、amber の淡い色）で描きます。重なっても、チートと貯めた分の両方がどれだけあったかがわかるようにするためです。
  - ちょうど同じとき：チートの位置に縦線を入れ、棒の下に「ぴったり、なかったことに。」と出します。
  - 「貯めた」の行：「🐷22回 🏃9回」のように回数と、貯めた分のkcal。貯めた分が0なら「まだありません」。
- **一番下の行**
  - まだの分があるとき：「あと◯kcalで、なかったことにできます」（回数の表示はやめます）
  - その下に「いちばん手軽に届く方法」（3章）と「ヒント ›」（4章）
  - 余りがあるとき：「チートにあと◯kcal使えます」と［今日食べる］［予定に入れる］（今のまま）。「好きなものを食べながら、ちゃんと痩せてます」はカードからは外し、トースト（体重のトーストなど）でだけ使います。
  - チートも貯めた分も0のとき：これまでどおりコンセプトの一文だけ（棒・換算の行は出さない）。
- 予定の行（「28日の焼肉まで…」）は、一番下の行のあとに出します。「メシためあと◯回」は「あと◯kcal」に直してください（「28日の焼肉まで、あと450kcal」）。
- カード全体を押すとログへ（今のまま）。ただし［記録する］［ヒント］［今日食べる］［予定に入れる］は、それぞれのボタンの動きを優先します。

## 3. いちばん手軽に届く方法（lib/calories.ts の純粋関数＋テスト）
- まだの分が **300kcal以下** のとき：ウォーキングで届く分数を出します。
  - 分数 ＝ まだの分 ÷ ウォーキングのkcal/分 を、10分単位で切り上げ
  - 「🚶 30分歩けば届きます」＋［記録する］
  - ［記録する］を押すと、うごための画面をウォーキング・その分数で開きます（すぐには保存しない。歩いたあとに保存してもらう）。
- 300kcalより多いときは、この行を出さず、「ヒント ›」を少し目立たせます（amber の文字など）。

## 4. ヒント
- 「ヒント ›」を押すと、下からシートを出します。中身はすべて定数と計算で作り、AIは使いません。
```
あと 1,200kcal

🐷 メシため          8回
🚶 ウォーキング      4時間（30分なら8回）
🏃 ランニング        2時間
👣 歩数              3万4千歩

ちょっとしたコツ
・飲み会の次の日の朝を、メシためにする
・ひと駅歩くと、だいたい15分（75kcal）
・夜をメシためにすると、翌朝の体重も軽くなりやすい
```
- 各行の数は、まだの分を それぞれのkcalで割って切り上げ（メシため150、ウォーキング・ランニングは既存のkcal/分、1000歩＝35kcal）。時間は分が60以上なら「◯時間◯分」、歩数は1万以上なら「◯万◯千歩」にまとめてください。
- 「ちょっとしたコツ」は `lib/calorieConstants.ts`（またはヒント用の定数ファイル）に3〜5個の固定の文として置き、全部出します。言葉は `CLAUDE.md` の「日本語の書き方」と、「我慢」「禁止」「食べすぎ」を使わないルールに従ってください。
- まだの分が0のときは、ヒントは出しません。

## 5. うごためを1タップで記録できる行
今日の記録の下（追加チートの行の下）に、今の「🏃＋うごため」ボタンの代わりに置きます。
```
今日うごく？
［🚶30分 150kcal］［🏃30分 300kcal］［👣歩数］［…］
```
- ［🚶30分］［🏃30分］：押すとその場でうごためとして保存し、トースト「🏃 うごため 30分。〜ぶんです」を出します。トーストに［取り消す］を5秒ほど出し、押されたらその記録を消します（`Toast.tsx` に操作ボタンがなければ足してください）。
- ［👣歩数］：歩数を入れる小さな入力を出して保存。
- ［…］：今のうごための画面（種類・時間を選べる画面）を開く。
- kcalの表示は既存のkcal/分から計算します（定数を画面に直接書かない）。
- その日にもううごためがあるときは、行の上に小さく「今日は 🚶30分・👣8,000歩」のように記録したものを出します。
- 表示中の日付が過去の日でも、その日の記録として使えます（今の過去7日のルールのまま）。

## 6. 今日の画面の整理
- **並び順**（上から）：日付の切り替え → 目標体重などのお知らせ（今のまま）→ 今朝の体重（今のまま上）→ **◯月のチート** → **今日の記録**（朝・昼・夜、追加チート）→ **今日うごく？** → v2.7 以降で足す行
- **「今日の目安」の3枚のカードはなくします。** 代わりに「今日の記録」の見出しの右に小さな［目安］ボタンを置きます。押すと下からシートを出し、朝・昼・夜の目安（「目安 ≒ ◯kcal」）と、それぞれのメニュー例（今の「?」の中身）を見られるようにします。
- **ヘッダー右の「目安 ◯kcal・減らすペース」の表示はなくします**（設定のタブで見られるので）。
- 体重タブの「これだけ食べて、月初めから変わらず」の行は、そのまま残してかまいません。

## 7. 言葉
- `CLAUDE.md` の「日本語の書き方」に従う。
- 画面に符号つきの数字を出さない。数字は3けたごとにカンマ。
- 「食べた」という言葉は、カードからはなくし「チート」にそろえます（予定のチートは入らないが、今日のチートは食べる前でも入るため）。

## 8. テスト（lib/calories.test.ts）
- 換算：いちばん多く食べた品で換算／品なしだけならラーメン／四捨五入／チート0なら行なし
- 体重の部分：減・変わらず・増（出さない）・計算できない（出さない）
- 棒：足りない部分の最低8%／超えた部分と縦線の位置／ちょうど同じ／貯めた分0
- いちばん手軽に届く方法：300kcal以下で10分単位の切り上げ／300kcalより多いと出さない
- ヒント：メシため・ウォーキング・ランニング・歩数の数、時間と歩数のまとめ方、まだの分0なら出さない
- 予定の行が kcal で出る
